MaleCNS v1.0의 Traced 뉴런과 시냅스 수를 이용한 LIF 모델입니다. 화면의 국소 명암을 시각 뉴런에 입력하고, DNa02 / DNa01 / MDN / DNp09 활동을 커서 움직임으로 변환합니다. 실제 초파리 비행이나 투자 판단을 재현한 모델은 아닙니다. 커서에 임의의 비행 경로를 추가하지 않습니다. 벽에서 반사되는 동작과 날갯짓은 화면 표현 규칙입니다.

각 화면 입력마다 막전위를 초기화하고 20 ms의 신경 반응을 계산합니다. 연속적인 뇌 상태나 기억을 재현하지 않습니다. 표시된 신경 시간은 반응 구간의 합계이며 실제 시간과 다릅니다. 시각 입력을 끄면 다음 반응 구간부터 출력이 없어집니다. 한 탭에서 실행해주세요.
