# Fly Cursor — Chrome 확장 프로그램

현재 웹사이트 위에 실제 MaleCNS 연결 기반의 초파리 가상 커서를 표시합니다. 운영체제 마우스는 움직이지 않으며 페이지 클릭·hover 이벤트를 합성하지 않습니다.

## 설치

1. 프로젝트의 Python 서버를 최신 코드로 실행합니다. 이전 서버가 있으면 Ctrl+C로 종료 후 다시 실행합니다.

   ```sh
   .venv/bin/python server.py
   ```

2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 우측 상단 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 선택합니다. ZIP 파일이나 프로젝트 전체 폴더가 아니라 `manifest.json`이 들어 있는 폴더입니다.
5. 일반 HTTP/HTTPS 사이트를 연 뒤 확장 프로그램 아이콘 → **현재 탭에서 시작**.
6. **Esc**, 팝업의 **정지 / 제거**, 탭 전환 또는 페이지 이동으로 정지합니다. 다른 페이지에서는 아이콘을 눌러 다시 시작합니다.

이 프로젝트에서 확장 프로그램 ID는 `joihphcnacjbfadninjbljiafgjegbbf`입니다. 공개 키를 manifest에 포함해 ID를 고정했으며 서버는 이 확장 origin만 추가 허용합니다. `key`를 제거하거나 변경하면 서버의 `extension-id.txt`도 맞춰야 합니다. 개인키는 확장에 포함하지 않습니다.

## 동작

콘텐츠 스크립트는 최상단 페이지의 Shadow DOM에 초파리·궤적·상태 표시를 그립니다. 클릭은 아래 사이트로 통과합니다. 서비스 워커가 현재 탭을 캡처하고, 초파리 중심 300×210 CSS px 시야를 회전·축소해 64×40 명암 배열로 만듭니다. 이 배열만 `http://127.0.0.1:8765/api/step`으로 보내고, 실제 신경 출력으로 다음 위치를 정합니다.

오버레이를 숨기지 않고 캡처합니다. 캡처 중 아이콘 위치만 고정하고, 신경 입력에서 아이콘·궤적·상태 표시 영역을 마스킹합니다. 가려진 원본 픽셀은 복구할 수 없으므로 남은 시야의 평균 명암으로 대체합니다(전체가 가려지면 0.5). 이는 실제 페이지 픽셀의 근사이며 별도의 감각 입력 가정입니다. 원본 캡처는 메모리에서만 처리하며 파일 저장·외부 업로드는 하지 않습니다. URL·텍스트·쿠키를 Python 서버로 보내지 않습니다. 페이지 자체의 네트워크 동작에는 관여하지 않습니다.

캡처 간격은 최소 650ms로, Chrome의 초당 2회 제한보다 느립니다. 실제 주기는 신경 계산 시간을 포함합니다. 초파리 날갯짓과 위치 보간은 화면 표현이며, 별도 임의 비행 경로는 없습니다. 신경 모델은 매 프레임 20ms 독립 반응이며 연속 기억은 없습니다. 자세한 모델 설명은 상위 README를 참고하세요.

## 권한과 제한

- `activeTab`: 사용자가 아이콘을 누른 탭에 일시적으로 접근.
- `scripting`: 선택한 탭에 가상 커서 주입.
- `storage`: 실행 탭과 일회성 실행 ID를 세션 메모리에 보관.
- `http://127.0.0.1/*`: 로컬 신경 서버에 접근. 코드는 8765 포트에만 요청합니다.
- 모든 사이트 상시 접근 권한, 실제 커서 제어 권한은 요청하지 않습니다.
- Chrome 내부 페이지, 웹 스토어, 일부 보호된 페이지에는 주입할 수 없습니다.
- 한 번에 한 탭만 실행합니다. 기존 Cursor Lab과 동시에 실행하면 같은 Python 모델의 RNG/집계 시간을 공유하므로 하나만 켜세요.
- 탭 전환 중 시작된 캡처는 완료 후 다시 현재 탭을 확인하고 폐기합니다. 브라우저 탭 전환과 캡처를 원자적으로 묶는 API는 아니므로 전환 순간 다른 탭의 이미지가 잠시 확장 메모리에 들어올 가능성은 있습니다. 그 프레임은 시뮬레이터로 전달하지 않습니다.
- 전체화면 요소, 페이지의 최상위 dialog, 특수 CSS가 있는 사이트에서는 오버레이가 가려질 수 있습니다.
- 확장 업데이트 후 기존 페이지를 새로고침하고 다시 시작하세요.

## 개발 검증

```sh
node --test tests/extension.test.cjs
.venv/bin/python -m unittest discover -s tests -v
```

자동 검증은 Chrome API 모의 환경에서 실행 상태·권한 경계·탭 전환·캡처 제한·명암 변환 경로를 검사합니다. 실제 Chrome의 unpacked 설치 및 캡처 권한 동작은 설치 후 확인해야 합니다.

공식 API: [activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab), [captureVisibleTab](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab).

## 표시와 포커스

시작에 성공하면 팝업은 자동으로 닫힙니다. 실행 창의 실제 탭 전환·페이지 이동·Esc에서 정지합니다. 다른 창의 탭 활성화와 창 포커스 변화만으로는 정지하지 않습니다.

아이콘의 머리는 보간된 실제 이동 벡터를 향합니다. 음수 이동 출력도 그대로 유지하며, 후진 시 그림만 진행 방향으로 돌립니다. 감각 입력의 방향과 운동 모델의 heading은 그대로이므로 아이콘의 방향과 내부 heading은 다를 수 있습니다.
